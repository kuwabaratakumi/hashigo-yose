# 掲載寄席の利用規約チェック（2026-10-16 時点）

一般公開の判断材料として、番組の取得元サイトの規約・サイトポリシーを確認した記録です。
法的な判断ではありません。規約は変わるので、公開前にもう一度確認してください。

判定の見方は、はしごシネマの記録（要許可／要配慮／記載なし）と同じです。

## まとめ

- **要許可は横浜にぎわい座**。一般公開するなら事前に問い合わせる。許可が出なければ `scraper/excluded.json` に入れて外す
- 記載なしの寄席も「許可されている」わけではない。寄席は芸人さん・協会（落語協会・落語芸術協会・上方落語協会）との関係が深いので、公開前に一言連絡しておくと安全
- 自分・社内だけで見る今の使い方（Cloudflare Access で閲覧者を限定）は、はしごシネマと同じ扱い
